🔄 Respaldo Automático Semanal
Configura un script gratuito de Google que respaldará automáticamente todos los datos cada semana a tu Google Drive o correo. Solo necesitas hacer la configuración una vez.
📋 Configuración del Respaldo Automático
No necesitas contraseñas ni secrets de Firebase.

Paso 1. Abre script.google.com con ludomentestudio@gmail.com
Paso 2. Toca + Nuevo proyecto
Paso 3. Borra todo el código que aparece y pega el código de abajo
Paso 4. Toca el botón ▶ Ejecutar una vez — autoriza los permisos de Google
Paso 5. Ve al ícono del 🕐 reloj (Activadores) → Agregar activador
Paso 6. Selecciona: respaldarLudoAssist → Semana → Lunes → 8am
¡Listo! Cada lunes a las 8am llegarás respaldo a tu correo y Google Drive
Los respaldos no reemplazan la protección de Firebase.
Son una capa extra de seguridad para tu tranquilidad.
